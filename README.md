# Conti da host

Calcolatore gratuito per host italiani di affitti brevi: dal 13 ottobre 2026 Airbnb trattiene il 15,5% dall'host. Scrivi il prezzo a notte di oggi e scopri quello nuovo per incassare come prima, con IVA sulla commissione e cedolare secca comprese. Confronta anche quanto resta su Airbnb, Booking e con una prenotazione diretta.

Online: https://regghy.github.io/conti-da-host/

Pagina singola (`index.html`), nessun dato inviato a server: le percentuali scelte restano solo nel browser di chi la usa.

Non è consulenza fiscale.
